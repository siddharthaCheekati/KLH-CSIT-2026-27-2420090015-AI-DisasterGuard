## Abstract

DisasterGuard is an adaptive web-based system developed to support users during natural and man-made disasters such as floods, cyclones, earthquakes, fires, landslides, and tsunamis. The system provides disaster-related information, safety instructions, emergency contacts, and incident reporting features. Users can report incidents by providing details such as disaster type, location, description, and photographs. The project follows Adaptive Software Engineering principles, allowing the system to be modified according to changing requirements and disaster situations. The main goal is to provide a simple and accessible platform that improves disaster awareness, communication, and emergency response.
